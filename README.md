# Obsidian Zhihu Sync Master 🚀

这是一个专为知乎创作者和深度读者打造的 Obsidian 内容备份工具。它可以将你的知乎回答快速转化为结构化的本地 Markdown 笔记，实现知识的永久存档。

## ✨ 核心特性

- **⚡ 一键全量同步**：只需填入 People ID，点击侧边栏图标，即可自动抓取你发布的最新回答（默认前 20 条），无需繁琐的复制粘贴。
- **📊 深度元数据抓取**：自动生成 YAML 属性（Properties），包含标题、URL、作者、话题、点赞数、评论数、回答日期及更新日期。
- **🖼️ 智能图片本地化**：自动抓取回答中的图片并保存至本地 `attachments` 文件夹。
- **♻️ 物理去重逻辑**：通过图片 ID 识别，确保同一张图在附件文件夹中仅存储一份，避免冗余占用空间。
- **📝 完美的 Markdown 转换**：针对知乎 HTML 结构深度优化，保留排版细节，支持 Obsidian 原生图片语法 `![[...]]`。

v0.2.1 | 增量快传版

- ⚡ 智能熔断：同步时自动对比本地文件日期。一旦发现旧内容已存在，立即停止请求，保护账号安全。

- 🔄 差异更新：如果知乎上的回答被你编辑过了，插件会识别到 updated_time 的变化并自动覆盖更新本地文件。

- 📁 结构加固：严格执行 answers/ 与 attachments/ 分离。

## 🛠️ 安装与配置

### 1. 编译安装

```bash
npm install
npm run dev

```

将编译后的文件放入 Obsidian 插件目录并启用。

### 2. 参数设置

在插件设置面板中配置以下信息：

- **知乎 Cookie**：从浏览器开发者工具 (F12) 获取 `www.zhihu.com` 的完整 Cookie。
- **我的 ID (People ID)**：进入个人主页，复制 URL 中 `people/` 后面的一串字符。
- **保存文件夹**：指定笔记存放路径。

---

## 🚀 使用指南

### 1. 同步我的回答 (一键模式)

点击侧边栏的 **用户图标 (User Icon)** 或 **循环图标**，插件将自动连接 API，把你主页的回答逐一搬运回本地。

### 2. 手动导入 (单篇模式)

点击侧边栏的 **链接图标 (Link Icon)**，粘贴特定的回答链接进行针对性抓取。

---

## 📂 数据结构

插件会为每一篇回答生成规范的 Properties 区域：

```yaml
---
标题: "你的回答标题"
url: https://www.zhihu.com/...
作者: 你的名字
点赞数: 1024
评论数: 56
回答日期: 2024-01-01
最后更新: 2024-03-20
---
```

---

## 💡 进阶：数据可视化

利用 Obsidian 的 **Dataview** 插件，你可以轻松创建一个“知乎创作仪表盘”：

```dataview
TABLE 点赞数, 评论数, 回答日期
FROM "Zhihu_Imports"
WHERE 作者 = "你的名字"
SORT 点赞数 DESC

```
