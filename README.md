# Obsidian Zhihu Loader 🚀

一个专为 Obsidian 用户设计的知乎内容抓取插件。它可以将知乎回答一键转换为 Markdown 格式，并自动处理图片本地化，让你的知识管理无缝衔接。

## ✨ 主要功能

- **一键导入**：通过知乎回答链接，快速抓取内容并存入 Obsidian。
- **图片本地化**：自动下载回答中的图片到本地 `attachments` 文件夹，防止知乎防盗链导致图片失效。
- **智能清理**：自动剔除知乎特有的 `svg+xml` 占位符，保持笔记整洁。
- **自动归档**：所有导入内容自动存放在 `Zhihu_Imports` 目录，并按“标题_ID”命名，防止冲突。
- **元数据保留**：自动在 YAML Frontmatter 中记录原链接、作者和日期。

## 🛠️ 安装方法

### 开发者模式（目前版本）
1. 下载本仓库到你的 Obsidian 库的 `.obsidian/plugins/` 目录下。
2. 在终端进入该文件夹，运行 `npm install` 安装依赖。
3. 运行 `npm run dev` 或 `npm run build` 进行编译。
4. 在 Obsidian 设置中开启 `Zhihu Loader` 插件。

## 🚀 使用指南

1. 点击侧边栏的 **链接图标** 或使用快捷键 `Cmd/Ctrl + P` 搜索 `导入知乎回答`。
2. 粘贴知乎回答的链接（例如：`https://www.zhihu.com/question/.../answer/...`）。
3. 等待片刻，插件会自动完成抓取、图片下载和 Markdown 转换。
